# 데모: Fit Any Labels (어떤 라벨이든 맞추기)

층별 2차원 데모의 초승달 점 200개에 라벨을 붙이고, 폭이 다른 신경망 네 개를 같은 점과 같은 라벨로 동시에 학습하는 웹 데모.
보여 주려는 내용: 같은 자리에 라벨이 다른 점이 없으면 충분히 큰 신경망은 어떤 라벨이든 학습 점을 거의 다 맞힌다. 무작위 라벨도 마찬가지다. 폭이 작은 신경망은 무작위 라벨을 외우지 못한다. 같은 자리에 라벨이 다른 점을 넣으면 어떤 신경망도 그 점들을 다 맞히지 못한다.
ANT6040(AI & Creativity)과 MAS1004에서 쓴다. 학습 정확도를 100%까지 끌어올리도록 조정하지는 않았다.

의존성 없는 단일 파일이다. `index.html` 하나를 브라우저로 열면 되고(`file://` 포함), 외부 네트워크 요청이 없다. 기본 UI는 영어이고 `?lang=ko`로 열면 한국어다.

## 화면

- 위 줄: 라벨 칩(실제, 무작위, 바둑판), 겹친 점 넣기, 학습/멈춤, 초기화, 속도(프레임마다 1, 5, 20걸음).
- 패널 네 개(폭 2, 8, 32, 64). 캔버스는 x −1.425 … 1.425, y −0.95 … 0.95를 가로세로 같은 배율로 보인다.
  - 배경: 입력 공간을 72×72 격자로 나눠 신경망이 예측한 종류의 색을 칠한다(종류 B 주황, 종류 A 파랑). 프레임마다 패널당 약 4ms 동안 줄 단위로 다시 계산한다.
  - 점: 종류 A는 원, 종류 B는 삼각형. 색은 층별 데모와 같게 원점 기준 각도로 정한다. 점은 지금 라벨의 모양과 색으로 그린다.
  - 겹친 점을 넣으면 겹친 두 점에 진한 테두리를 두른다.
  - 패널 아래 큰 숫자: 학습 정확도.
- 아래: 걸음 수와 걸음마다 학습 정확도 그래프. 폭마다 선 하나(폭이 클수록 진한 색)이고, 세로축은 40% … 100%다. 겹친 점을 넣으면 가능한 최고 정확도를 빨간 점선과 "best possible 95.2%"로 그린다.
- 점을 누르면(어느 패널이든) 그 점의 라벨이 바뀐다. 라벨 칩, 겹친 점 넣기, 점 누르기는 모두 학습을 멈추고 같은 처음 노브 값에서 다시 시작한다. 지금 라벨 칩을 다시 누르면 누른 점의 변경이 지워진다.
- 초기화: 모든 패널에 새 시드의 처음 노브 값을 뽑는다(모든 패널이 같은 시드).
- 학습은 3,000걸음(`PRESET.maxSteps`)에서 저절로 멈춘다. 한 프레임의 학습이 40ms를 넘으면 그 프레임은 정한 걸음 수보다 적게 학습한다.
- `Space`: 학습과 멈춤.

## URL 옵션

| 옵션 | 값 | 용도 |
| --- | --- | --- |
| `labels` | `real`, `random`, `checker` | 라벨 (기본 `real`) |
| `overlap` | `1` | 겹친 점을 넣고 연다 |
| `train` | `1` | 열자마자 학습 시작 |
| `lang` | `ko` | 한국어 화면 |

예: `index.html?lang=ko&labels=random&overlap=1`.

## 데이터와 라벨

- 점: 층별 2차원 데모의 Two moons 학습 점 200개(종류별 100개, 시드 `lb|v1|data|moons`). 점 생성 코드를 그대로 복사했고, `test/core.test.js`가 층별 데모의 `index.html`을 불러 좌표와 라벨을 대조한다.
- 실제: 초승달의 종류.
- 무작위: 점마다 시드 `fa|v1|random`의 동전 하나(0.5 확률로 종류 B). 종류 B는 200개 중 개수가 정해져 있지 않다.
- 바둑판: 좌표를 0.25 간격의 칸으로 나눠 (⌊x/0.25⌋ + ⌊y/0.25⌋)이 홀수면 종류 B.
- 겹친 점: 시드 `fa|v1|overlap`으로 서로 다른 점 10개를 고르고, 각 점과 좌표가 똑같고 라벨이 반대인 점을 하나씩 더한다(모두 210개). 같은 자리의 두 점 중 하나만 맞힐 수 있으므로 가능한 최고 학습 정확도는 200/210 = 95.24%다. `FA.bestAcc`가 좌표가 같은 점끼리 묶어 많은 쪽 라벨의 개수를 더해 계산한다. 겹친 점의 짝을 누르면 둘 다 라벨이 바뀌어 반대 라벨이 유지된다.

## 모델과 학습

- 신경망: 입력 2 → H → H → 1, 은닉층 둘은 tanh, 출력에 sigmoid. H는 2, 8, 32, 64.
- 처음 노브 값: 시드 `fa|init|<1 + 초기화 횟수>`의 정규분포(W1 표준편차 √(1/2), W2와 w3 √(1/H)), 편향 0.
- 손실: 학습 점 전체의 이진 교차 엔트로피 평균. 기울기는 역전파로 구하고 테스트에서 중앙 차분과 대조한다.
- 갱신: 전체 배치 Adam(β₁ 0.9, β₂ 0.999, ε 1e−8), 학습률 0.01. 한 걸음마다 네 신경망을 한 번씩 갱신한다.

- 폭 2, 8, 32, 64에서 헤드리스 크로미움 151의 학습 속도(스모크 테스트가 출력한 값): 프레임마다 20걸음이면 초당 171걸음, 1걸음이면 초당 48걸음. `train(1000)`은 4.2초 걸렸고, 1,000걸음 뒤 무작위 라벨의 학습 정확도는 폭 2부터 57%, 76.5%, 91%, 98.5%로 Node와 같았다. 겹친 점을 넣으면 55.7%, 71.4%, 88.6%, 92.9%였다.

- 시드 하나로 잰 값이다. 초기화로 시드를 바꾸면 걸음 수와 정확도가 조금씩 달라진다. 크로미움과 Node는 부동소수점 계산이 조금 달라 화면의 값이 표와 몇 걸음씩 어긋날 수 있다.

## 구조

한 파일 안에 스크립트가 두 개다.

- `<script id="fa-core">` (전역 `FA`, DOM 없음): 난수, 초승달 점, `LABELINGS`와 `makeLabels(name, moons)`, `OVERLAP_K`, `overlapIndices(n)`, `buildData(moons, y, overlap)`(`{ n, X, y, base }`), `bestAcc(data)`, `WIDTHS`, `initNet(H, seed)`, `params`, `logit`, `evaluate`, `lossGrad`, `makeAdam`, `adamStep`, `PRESET = { lr, steps, maxSteps }`, `STRINGS = { en, ko }`, `t(lang, key, params)`.
- `<script id="fa-ui">` (전역 `FAUI`): 화면, 학습 루프, 결정 영역, URL 옵션.
  - `FAUI.hooks`: `setLabels(name)`, `setOverlap(on)`, `flip(i)`, `train(n)`, `startTraining()`, `stopTraining()`, `reset()`, `shadeNow()`, `draw()`, `state()`. `setLabels`, `setOverlap`, `flip`, `train`, `reset`은 끝난 뒤의 `state()`를 돌려준다.
  - `state()`는 `{ steps, labels, overlap, bestAcc, training, lang, panels: [{ width, acc, loss }] }`.
  - 요소 id: `#segLabels`(칩은 `button[data-v]`), `#bOverlap`, `#bTrain`, `#bReset`, `#speed`, `#panels`(패널마다 `section.panel[data-w]` 안에 `h3`, `canvas.pc`, `b.acc`), `#legend`, `#chartWrap`, `#chartHead`, `#bestKey`(겹친 점이 있을 때만), `#accCv`, `#sSteps`, `#note`, `#fine`.

## 테스트

`test/`는 게시할 때 복사되지 않는다.

```bash
node --test test/*.test.js                          # 코어 (6개)
node test/measure.js 64 random 0 4000               # 폭 하나, 라벨 하나 실측
uv run --with playwright python test/smoke.py       # 브라우저 스모크, 캡처는 test/shots/
```

- 코어 테스트: 층별 데모의 초승달과 같은지, 라벨 세 가지의 시드 고정과 바둑판 규칙, 겹친 점을 넣으면 210개이고 짝마다 좌표가 같고 라벨이 반대이며 `bestAcc`가 200/210인지, 역전파와 중앙 차분, 문자열 표 en과 ko의 키와 자리표시, `PRESET.steps` 안에 폭 64가 무작위 라벨의 95% 이상을 맞히고 폭 2는 90% 미만인지.
- 스모크: 콘솔 에러, 기본 화면, 라벨 칩, `train(50)`, 겹친 점 넣기(210개, 점선과 "best possible 95.2%"), 점을 눌러 라벨 바꾸기와 `flip(i)`, 초기화, 학습 루프 속도, `maxSteps`에서 멈추는지, URL 옵션, `lang=ko`, 좁은 창.
