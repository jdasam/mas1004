# 데모: Layer by Layer in 2D (층마다 2차원 공간이 바뀌는 과정)

두 클래스로 나뉜 2차원 점을 폭 2짜리 신경망에 넣고, 층 하나가 공간을 어떻게 바꾸는지 단계별로 재생하는 인터랙티브 웹 데모.
행렬 곱은 회전, 늘이기(필요하면 뒤집기), 회전으로 나눠 정확한 각도와 배율로 움직이고, 편향은 이동으로, 활성화 함수는 좌표마다 휘거나 꺾거나 눌러 붙이는 움직임으로 보인다.
입력과 모든 은닉 상태가 2차원이라 어느 단계의 공간이든 평면 하나에 그대로 그린다.
MAS1004(Data & AI)와 ANT6040(AI & Creativity) 2주차 4부에서 같이 쓴다.

설계 문서: `docs/superpowers/specs/2026-09-14-layer-by-layer-2d-design.md`, 구현 계획: `docs/superpowers/plans/2026-09-14-layer-by-layer-2d-plan.md`.

의존성 없는 단일 파일이다. `index.html` 하나를 브라우저로 열면 되고(`file://` 포함), 빌드 단계도 외부 네트워크 요청도 없다. 기본 UI는 영어이고 `?lang=ko`로 열면 한국어 화면이다.

## ANT6040 2주차를 위해 더한 것

- 데이터 Two blobs(덩어리 둘): 중심 (−0.7, 0.25)와 (0.7, −0.25), 표준편차 0.22, 종류별 100개. 규칙 x > 0이 학습 점 99.5%(199/200), 테스트 점 100%를 맞힌다. 프리셋은 층 0개.
- 층 0개: 입력 공간에 직선 v·x + c = 0 하나만 놓는다. 층 수는 0 … 8.
- 테스트 점: 데이터마다 종류별 50개(시드 `lb|v1|test|<이름>`)이고 학습에 쓰지 않는다. Show test points를 켜면 모든 공간에 속 빈 마커로 보이고 테스트 정확도가 붙는다.
- 손실 표시: 캔버스 왼쪽 위에 손실과 정확도를 크게 둔다. 입력 공간과 출력 공간에서만 예측이 라벨과 다른 점에 진한 회색 테두리를, 점마다 손실 −log p(정답)에 비례하는 회색 후광(반지름은 점 반지름 + 22 × min(손실, 4)/4)을 그린다.
- 새 점: 재생 위치가 입력일 때(층이 0개면 언제나) 캔버스를 누르면 속 빈 마름모가 생기고, 옆에 예측한 종류와 그 확률(예: B 0.93)이 뜬다. 이후 공간에서도 같은 단계를 거쳐 옮겨 가고 학습에는 쓰지 않는다. Clear new points로 지우고, 데이터를 바꾸면 지운다.
- 오른쪽 아래 탭 셋. 처음에는 Train 탭이 열린다.
  - Knobs: 재생 위치의 층(입력이면 층 1, 출력이면 마지막 층)의 w₁₁ w₁₂ w₂₁ w₂₂ b₁ b₂와 출력의 v₁ v₂ c를 슬라이더(−3 … 3, 0.01 단위)와 숫자 칸으로 바꾼다. 노브를 움직이면 학습을 멈추고 그 층의 Adam 상태만 초기화한다.
  - Gradient: 고른 노브만 바꿀 때의 손실 곡선(지금 값 ± 2, 61점), Δ(1, 0.1, 0.01)만큼 밀어 잰 기울기, 모든 노브를 밀어서 잰 기울기(손실 계산 노브 수 + 1번), 역전파로 잰 기울기(역전파 1번), 마지막으로 잰 기울기로 모든 노브를 w ← w − 학습률 × 기울기만큼 옮기는 한 걸음. 한 걸음 가면 표가 비고, 다시 재기 전에는 한 걸음 버튼이 꺼진다. 학습률은 Train 탭과 같은 값이다.
  - Train: 기존 버튼과 통계에 갱신 규칙(gradient descent, Adam) 선택을 더했다. 기본 규칙과 학습률은 아래 "프리셋 실측"으로 정했다.
- 한국어 화면: 버튼, 탭, 캡션, 단계 문구를 코어의 문자열 표 `LB.STRINGS`(en, ko, 키가 같다)에서 `LB.t(lang, key, params)`로 뽑는다.

## 수업에서 쓰는 법

진행 예:

1. XOR (`?data=xor`). Train을 눌러 정확도 100%까지 학습한다(1초 안쪽). ⏮로 입력으로 돌아가 Play.
   층 1에서 평면이 몇 도 돌고, 어느 축으로 몇 배 늘고, 다시 돌고, 옮겨진 뒤 tanh로 (−1, 1) 상자 안에 눌리는 것을 본다.
   마지막 Readout에서 직선 하나가 두 클래스를 가르고, 섬네일 줄의 Input에서는 같은 경계가 곡선으로 보인다.
2. Two moons. 섬네일 줄(Input, after layer 1, …, Readout)만 차례로 눌러 층 출력만 훑는다.
3. Two spirals. Layers를 2로 줄이고 Reset, Train. 대개 99%에 닿지 못한다(탐색 실험에서 1회전 나선, leaky ReLU 2층의 중앙값 88%).
   멈춘 상태에서 + 버튼으로 층을 하나씩 더하며 학습을 이어 가면 기존 가중치는 그대로 두고 새 층이 더해져 점이 풀린다.
4. Activation을 ReLU로 바꿔 같은 일을 한다. 두 좌표가 모두 음수인 점은 원점 한 점으로 눌리고 되돌릴 수 없다. 층이 많을수록 학습이 멈추는 경우가 잦다.
5. Color by를 along the curve로 바꾸면 나선 팔의 안쪽 끝과 바깥쪽 끝이 어느 층에서 어디로 가는지 색으로 따라갈 수 있다.

수업 화면에서 학습 속도를 느리게 보이려면 speed를 1 step per frame으로 둔다.

## 화면

- 큰 캔버스: 지금 재생 위치의 공간. 점, 입력 격자가 같은 단계를 거쳐 휜 모습(회색 선), 이 공간의 좌표축과 눈금.
  - 회전 중: 이 층 입력 공간의 (1, 0), (0, 1)이 지금까지의 단계를 거친 화살표, 회전 전 방향에서 지금 방향까지의 호와 각도.
  - 늘이기 중: x축과 y축 위의 ±배율 눈금과 "×1.62 along x" 같은 숫자.
  - 뒤집기 중: 가로축 강조와 "flip: y becomes −y".
  - 이동 중: 원점에서 b까지 점선 화살표.
  - 활성화 중: tanh는 [−1, 1] 상자, ReLU와 leaky ReLU는 꺾이는 두 축을 진하게.
  - 입력과 Readout에서는 예측 클래스로 배경을 칠한다. Readout에서는 직선 v·h + c = 0을 그린다.
- 섬네일 줄: 입력, 층마다 출력, Readout. 누르면 그 자리로 간다.
- 단계 막대: 단계마다 한 칸. 누르거나 끌어서 재생 위치를 옮긴다.
- 오른쪽 위: 지금 층의 W, b, det W, 단계 표. 행을 누르면 그 단계를 재생한다.
- 오른쪽 아래: 학습(Train, +1 step, +10 steps, Reset, learning rate, speed, loss, accuracy, steps, 손실 곡선).
  손실이 0.01 아래로 내려가거나 20,000걸음이 되면 멈춘다.

## 데이터와 모델

- 점은 클래스마다 100개. 시드 고정(`lb|v1|data|<이름>`, `DATA_VERSION = 1`).
  - Two moons: 반원 두 개, 잡음 0.08, 0.8배 축소.
  - XOR: (±0.7, ±0.7) 네 덩어리, 잡음 0.15, 대각선 두 쌍이 같은 클래스.
  - Two spirals: 반지름 t, 각도 2πt(1회전), 두 번째 팔은 180° 돌림, 잡음 0.03, 1.15배.
- 클래스 A는 원(색상 140° → 225°), 클래스 B는 삼각형(0° → 48°). 색은 입력 공간에서 정하고 끝까지 바꾸지 않는다.
- 모델: `h ← act(W h + b)`를 층 수만큼, W는 2×2, b는 2차원. 마지막에 `p = sigmoid(v·h + c)`가 클래스 B일 확률.
  활성화는 tanh, leaky ReLU(음수 쪽 기울기 0.1), ReLU 중 하나를 네트워크 전체에 쓴다.
- 초기값: W와 v는 표준정규분포, b는 표준편차 0.1. 무작위 회전과 배율로 W를 뽑는 방식도 재 봤지만 성공 비율이 나아지지 않았다(XOR에서는 나빠졌다).
- Add layer는 마지막 층 뒤에 W = I + 잡음(표준편차 0.05), b = 0인 층을 붙이고 기존 가중치를 그대로 둔다. Remove layer는 마지막 층을 뗀다.

## 계산 방식

### 행렬 분해

2×2 행렬을 닫힌 식으로 `W = R(θ₂) · diag(s₁, s₂) · F · R(θ₁)`로 쓴다. R(θ)는 반시계 방향 θ 회전, F = diag(1, −1)은 det W < 0일 때만 들어가는 뒤집기다.

```
E = (a+d)/2, F = (a−d)/2, G = (c+b)/2, H = (c−b)/2
Q = √(E²+H²), R = √(F²+G²), s₁ = Q+R, s₂ = Q−R
α₁ = atan2(G, F), α₂ = atan2(H, E), θ₁ = (α₂−α₁)/2, θ₂ = (α₂+α₁)/2
```

같은 W를 쓰는 조합이 여럿이다(θ₁을 90°씩 옮기고 θ₂를 반대로 옮기며 s₁, s₂를 바꾸는 것). 화면의 회전이 가장 작도록 |θ₁| + |θ₂|가 가장 작은 조합을 고른다.
s₁ = s₂이면 두 회전이 하나로 합쳐지므로 θ₁ = 0으로 둔다(순수 회전 행렬은 회전 한 번으로 보인다).

예: W = [[1.2, −0.8], [0.5, 0.9]], b = (0.3, −0.1), tanh

```
rotate 38.4° counterclockwise
stretch ×1.45 along x, ×1.02 along y
rotate 6.6° clockwise
shift by (0.30, −0.10)
tanh: squash each coordinate into (−1, 1)
```

### 단계 식

재생 진행도 t가 0에서 1로 갈 때 점 p에 적용하는 식이다. 점과 격자에 같은 식을 쓴다.

| 단계 | 식 |
| --- | --- |
| rotate | R(θ t) p |
| flip | diag(1, 1 − 2t) p |
| stretch | diag(1 + t(s₁ − 1), 1 + t(s₂ − 1)) p |
| shift | p + t b |
| activation | (1 − t) p + t act(p) |

모든 단계를 t = 1까지 차례로 적용한 결과가 순전파 `act(W p + b)`와 1e−9 안에서 같다(테스트).
각도 0.05° 미만의 회전, 배율 차이 0.005 미만의 늘이기, 크기 0.005 미만의 이동은 표에 남기되 재생 시간을 0.35배로 줄인다.

### 재생과 카메라

- 1× 속도에서 단계 하나는 1.6초. 앞 15%는 카메라 이동, 15%에서 90%까지 점의 움직임(smoothstep), 나머지는 정지.
- 카메라 범위는 단계 전후 두 상태의 점과 원점을 모두 담는다. 움직이는 동안에는 카메라를 고정해서 늘이기가 실제로 커지고 작아지는 것으로 보인다. 가로세로 배율은 같게 두어 각도가 화면에서 그대로 보인다.

### 학습

- 손실은 이진 교차 엔트로피 평균, gradient는 역전파(테스트에서 중앙 차분과 대조).
- 한 걸음에 200점 전체를 쓴다. 갱신 규칙은 둘 중 하나다.
  - 경사하강법(gradient descent): 모든 노브(가중치와 편향)를 `w ← w − 학습률 × 기울기`로 옮긴다.
  - Adam(β₁ 0.9, β₂ 0.999): 노브마다 걸음 크기를 따로 정한다. 층마다 걸음 수를 따로 세서 새로 더한 층도 편향 보정이 처음부터 맞다.
- 학습 칸 아래 한 줄이 지금 쓰는 갱신 규칙을 적는다.
- 학습률 슬라이더는 로그 눈금으로 10⁻³ … 10¹이다.

### 갱신 규칙

기본 갱신 규칙은 프리셋마다 아래 "프리셋 실측"으로 정했다.

- 경사하강법의 가장 좋은 학습률이 시드 30개 중 24개 이상에서 3,000걸음 안에 목표 정확도에 닿으면 경사하강법, 아니면 Adam을 기본으로 둔다. 가장 좋은 학습률은 목표에 닿은 시드가 많은 것이고, 같으면 도달 걸음 중앙값이 작은 것이다.
- 프리셋의 `lr`에는 두 규칙 각각의 가장 좋은 학습률을 적는다.
- `seed`는 기본 규칙에서 시드 1이 목표에 닿으면 1이다. `steps`는 그 시드의 도달 걸음에 1.5를 곱해 500 단위로 올린 값이고, 최소 1,000이다.

## 프리셋 실측

`node test/calibrate.js`(시드 1…30, 최대 3,000걸음)로 정했다. 데이터마다 두 갱신 규칙에서 가장 좋은 학습률을 한 행씩 적었고, "(기본)"이 프리셋의 기본 규칙이다.

| 데이터 | 설정 | 갱신 규칙 | 학습률 | 목표 도달 시드 | 도달 걸음 중앙값 | 기본 시드 |
| --- | --- | --- | --- | --- | --- | --- |
| Two blobs | 층 0개 | 경사하강법 (기본) | 3 | 30/30 (100%) | 10 | 시드 1: 63걸음 |
| Two blobs | 층 0개 | Adam | 0.1 | 30/30 (100%) | 38 | 시드 1: 6걸음 |
| Two moons | tanh 3층 | 경사하강법 (기본) | 0.5 | 27/30 (100%) | 272 | 시드 1: 1,380걸음 |
| Two moons | tanh 3층 | Adam | 0.02 | 28/30 (100%) | 242 | 시드 1: 1,192걸음 |
| XOR | tanh 3층 | 경사하강법 (기본) | 0.5 | 24/30 (100%) | 53 | 시드 1: 33걸음 |
| XOR | tanh 3층 | Adam | 0.02 | 26/30 (100%) | 56 | 시드 1: 25걸음 |
| Two spirals | leaky ReLU 4층 | 경사하강법 | 1 | 9/30 (99%) | 1,087 | 시드 1: 3,000걸음 안에 못 닿음 (80%) |
| Two spirals | leaky ReLU 4층 | Adam (기본) | 0.05 | 27/30 (99%) | 363 | 시드 1: 95걸음 |

초승달 tanh 1층은 목표 없이 3,000걸음 뒤의 학습 정확도를 쟀다. 경사하강법 학습률 1에서 시드 30개 중 6개가 100%, 24개가 87.5~94%(30개 중앙값 91.5%)였고, Adam 0.02에서는 3개가 100%, 27개가 87.5~92.5%(중앙값 92.5%)였다.
나선에서 경사하강법은 학습률 0.3에서 6/30, 1에서 9/30만 99%에 닿아 기준(24/30)에 못 미치므로 Adam을 기본으로 둔다.

그 밖에 잰 학습률: 덩어리 경사하강법 0.3과 1은 30/30(중앙값 107, 32걸음), Adam 0.02와 0.05는 30/30(272, 96걸음). 초승달 3층 경사하강법 0.3은 26/30, 1은 23/30, 2는 12/30. XOR 경사하강법 1은 23/30, 2는 22/30.

층 수는 이전 측정(Adam, 최대 4,000걸음)으로 골랐다. 2층은 초승달 tanh 14~19/30, XOR tanh 16~18/30이었고, 실패한 시드는 초승달 92%, XOR 75% 근처에서 멈췄다.
나선은 100%까지 가는 시드가 30개 중 12개라 목표를 99%로 두었다. 두 팔이 만나는 중심 근처의 잡음 점 한두 개가 남는다.

## 구조

한 파일 안에 스크립트가 두 개다.

- `<script id="lb-core">` (전역 `LB`): 난수, 데이터, 네트워크, 역전파, Adam, 행렬 분해, 단계, 추적, 문구, 프리셋. DOM을 건드리지 않는다.
- `<script id="lb-ui">` (전역 `LBUI`): 화면, 재생, 학습 루프, URL 옵션. `LBUI.hooks`는 스모크 테스트용.

코어만 Node에서 쓰려면:

```js
const core = require('./test/load.js')();
const d = core.decompose(Float64Array.from([1.2, -0.8, 0.5, 0.9]));
// { theta1: 0.6698 (38.4°), flip: false, s1: 1.447, s2: 1.023, theta2: -0.1155 (−6.6°) }
```
