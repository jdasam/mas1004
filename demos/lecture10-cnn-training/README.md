# 데모: CNN Training (작은 CNN이 MNIST를 학습하는 동안 필터와 특징 맵이 바뀌는 모습)

9차시 덱의 작은 CNN(필터 8개 1 × 3 × 3 → max pooling → 필터 16개 8 × 3 × 3 → max pooling → 784 × 10, 파라미터 9,098개)을 브라우저에서 실제로 학습하면서, 고른 입력 이미지 하나에 각 필터가 얼마나 반응하는지 함께 보여 준다.
MAS1004 10차시(2026-10-08) 수업 중 프로젝터용. 설계: `docs/superpowers/specs/2026-10-08-lecture10-cnn-training-design.md`.

- 왼쪽: 입력 이미지(마우스로 그리기, 시험 이미지 10장 중 고르기, 화살표로 2픽셀씩 옮기기, Clear), 이 입력의 확률 막대 10개, 손실 곡선(학습 배치 평균, 시험 2,000장).
- 가운데: 1층 필터 8개(지금 값은 크게, step 0 값은 작게. 빨강 양수, 파랑 음수, ±0.6에서 색이 가득 찬다)와 그 아래 입력의 특징 맵(28 × 28, ReLU 뒤). 칸이 40픽셀 이상이면 필터 칸에 숫자도 쓴다.
- 오른쪽: 2층 특징 맵 16장(14 × 14, ReLU 뒤). 맵을 클릭하면 그 맵을 만든 2층 필터를 3 × 3 조각 8개(±0.3에서 색이 가득 찬다)로 보여 주고, 위에 각 조각이 곱해지는 1층 맵(max pooling 뒤 14 × 14)을 둔다.
- 특징 맵 색은 0이 흰색이고, 같은 층 안의 가장 큰 값에서 가장 진하다. 약하게 반응한 필터의 맵은 흐리다. 맵마다 가장 큰 값을 숫자로 붙인다.
- `Top images` 보기(위쪽 줄 View): 필터마다 시험 이미지 2,000장 중 특징 맵의 최댓값이 가장 큰 8장을 큰 순서로 보여 준다. `Layer 1 | Layer 2`로 층을 고른다.
  - 빨간 사각형은 그 최댓값이 계산에 쓰는 입력 영역이다. 1층은 3 × 3, 2층은 8 × 8(풀링 뒤 3 × 3칸, 칸마다 1층 2 × 2칸, 1층 칸마다 3 × 3픽셀). 가장자리에서는 잘린다.
  - 이미지 아래는 그 최댓값과 정답 숫자. 이미지를 클릭하면 그 이미지가 Training 보기의 입력이 되고, 2층이면 그 필터가 선택된다.
  - 이 보기가 열려 있는 동안 모델이 바뀌면 모델을 복사해 프레임마다 나눠 다시 찾는다(2,000장에 약 0.3초). 학습 중에는 목록이 계속 바뀐다.
  - 1층은 3 × 3 조각이 잉크로 가득 차면 같은 최댓값이 여러 이미지에서 나와 순위가 같은 값으로 이어진다. 같은 값이면 시험 세트에서 앞에 있는 이미지가 먼저다.

- GitHub Pages: `mas1004-2026/tools/publish_demo.sh lecture10-cnn-training` → https://jdasam.github.io/mas1004/demos/lecture10-cnn-training/

## 조작

- Play/Pause(`Space`), +1 step(`→`), +10 steps, Reset(같은 시드로 처음부터, 매번 같은 학습).
- Steps/s: 1, 5(기본), 20, 100, Max(이 컴퓨터의 크로미움에서 초당 약 100걸음).
- Learning rate: 0.01, 0.1(기본), 1. 바꾸면 다음 걸음부터 적용된다. 비교하려면 Reset 뒤에 바꾼다.
- URL 옵션: `?lr=1`, `?speed=20`(또는 `max`), `?play=1`, `?seed=2`, `?img=0`(처음 입력으로 쓸 시험 이미지 번호, 기본 0번은 8), `?view=top`, `?layer=2`.

## 학습

배치 32의 확률적 경사 하강법. 1 epoch = 313걸음(마지막 배치 16장), epoch마다 시드 고정으로 다시 섞는다.
초기값은 PyTorch 기본값처럼 균등분포 ±1/√(입력 수)(1층 ±1/3, 2층 ±1/√72, 마지막 층 ±1/28), 편향도 같다.
시험 2,000장 평가는 한 번에 약 0.3초가 걸려서 모델을 복사해 두고 프레임마다 조금씩 나눠 계산한다. 곡선 점은 2걸음(20걸음까지), 5걸음(100까지), 20걸음(400까지), 그 뒤 50걸음마다 찍되 앞 평가가 끝나야 다음을 시작한다.

## 실측 (`node test/measure.js 3`, 시드 1)

| 학습률 | 10걸음 | 50걸음 | 100걸음 | 1 epoch | 3 epoch |
| --- | --- | --- | --- | --- | --- |
| 0.01 | 10.0% | 14.6% | 25.3% | 78.0% | 90.9% |
| 0.1 | 20.9% | 72.3% | 89.0% | 94.8% | 96.8% |
| 1 | 17.2% | 9.4% | 9.8% | 10.2% | 12.4% |

시험 정확도(2,000장). 9차시 덱의 PyTorch 실측은 5 epoch 뒤 97.2%였다.
학습률 1에서는 10걸음쯤까지 2층 맵이 진해졌다가 20~30걸음 사이에 2층의 ReLU가 거의 모두 0이 되어 맵 16장이 비고, 1층 필터 몇 개가 파랗게 가득 차며, 정확도가 10% 근처에 머문다.
학습률 0.1에서도 120걸음 근처에서 시험 손실이 0.33에서 0.65로 잠깐 튀었다가 돌아온다(배치 하나의 큰 걸음).
처음부터 거의 반응하지 않는 1층 필터가 있다(시드 1에서는 2번과 5번, 시험 이미지 0번에서 가장 큰 값이 0.1 미만). 학습 뒤에도 그대로인 경우가 많다.

## 구조와 테스트

- `index.html`: `<script id="cn-core">`(전역 `CN`, DOM 없음: 데이터 분할, 모델, 순전파, 역전파, SGD, 평가, 필터별 상위 이미지, 입력 영역)와 `<script id="cn-ui">`(화면, 학습 루프, 그리기).
- `test/`(게시에서 빠진다):

```bash
node --test test/core.test.js                                  # 파라미터 수, 단순 구현과 순전파 대조, 역전파와 중앙 차분 대조, 상위 이미지와 전수 탐색 대조, 입력 영역 밖 픽셀이 값을 바꾸지 않음 등 8개
node test/measure.js 3                                         # 위 실측 표와 걸음당 시간, 필터와 특징 맵의 크기
uv run --no-project --with playwright python test/smoke.py     # 브라우저 캡처(학습, 그리기, 이동, 2층 맵 클릭, Top images 보기와 클릭), test/shots/
```
