# 데모: Same Moons, Shuffled Labels (같은 초승달, 섞은 라벨)

층별 2차원 데모의 초승달 점 200개로 같은 신경망 두 개를 나란히 학습하는 웹 데모.
왼쪽 패널은 실제 라벨로, 오른쪽 패널은 같은 점의 라벨을 시드로 한 번 섞어서 학습한다. 두 신경망은 같은 처음 노브 값에서 시작하고, 한 걸음마다 둘 다 한 번씩 갱신한다.
은닉층 폭이 64이면 두 패널 모두 학습 정확도 100%에 닿는다. 학습에 쓰지 않은 테스트 점의 정확도는 왼쪽이 100%, 오른쪽이 44%다. 폭이 4이면 오른쪽 패널은 학습 점도 다 맞히지 못한다(6,500걸음 뒤 71.5%).
ANT6040(AI & Creativity) 2주차에서 쓴다.

설계 문서: `docs/superpowers/specs/2026-09-14-ant6040-week02-redesign-design.md` 6.2절, 구현 계획: `docs/superpowers/plans/2026-09-14-ant6040-week02-redesign-plan.md` 과제 B1~B3.

의존성 없는 단일 파일이다. `index.html` 하나를 브라우저로 열면 되고(`file://` 포함), 빌드 단계도 외부 네트워크 요청도 없다. 기본 UI는 영어이고 `?lang=ko`로 열면 한국어다.

## 수업에서 쓰는 법

진행 예 (`?lang=ko`, 기본 시드):

1. 폭 64 그대로 학습을 누른다. 왼쪽은 47걸음에 학습 정확도 100%가 되고, 오른쪽은 1,400걸음 남짓 걸려 100%가 된다. 두 패널이 함께 100%가 되면 학습이 저절로 멈춘다(헤드리스 크로미움 151에서 1,415걸음, 프레임마다 5걸음이면 15초쯤, 20걸음이면 10초쯤).
   아래 손실 곡선에서 실제 라벨의 실선은 금방 바닥에 닿고, 섞은 라벨의 점선은 천천히 내려온다.
   왼쪽 결정 영역은 두 초승달 사이를 지나는 매끈한 경계 하나이고, 오른쪽은 점 사이로 가늘게 갈라진 조각이 많다.
2. 테스트 점 보기를 누른다. 학습에 쓰지 않은 점 100개가 속 빈 마커로 나타나고 테스트 정확도가 보인다. 왼쪽 100%, 오른쪽 44%. 예측이 틀린 테스트 점에는 진한 회색 테두리가 둘린다.
3. 폭을 4로 바꾸고 학습을 누른다. 왼쪽은 189걸음에 100%가 되지만 오른쪽은 70% 안팎에서 더 오르지 않는다. 적당한 곳에서 멈춤을 누른다(누르지 않으면 13,000걸음에서 멈춘다).

초기화를 누르면 두 패널에 같은 새 처음 노브 값을 뽑는다. 폭 64에서 시드 30개 중 2개는 6,000걸음 안에 섞은 라벨을 다 외우지 못했다(아래 실측).

## 화면

- 위 줄: 폭 칩(4, 16, 64, 256), 학습/멈춤, 초기화, 속도(프레임마다 1, 5, 20걸음), 테스트 점 보기.
- 두 패널(왼쪽 실제 라벨, 오른쪽 섞은 라벨). 캔버스는 x −1.6 … 1.6, y −1.2 … 1.2를 가로세로 같은 배율로 고정해 보이고, 가는 좌표축과 눈금을 그린다.
  - 배경: 입력 공간을 96×96 격자로 나눠 신경망이 예측한 종류의 색을 칠한다(종류 B 주황, 종류 A 파랑, 불투명도 0.2). 프레임마다 패널당 약 6ms 동안 줄 단위로 다시 계산하고 다음 프레임에 이어서 계산한다. 아직 다시 계산하지 않은 줄은 이전 그림이 남는다.
  - 학습 점: 종류 A는 원, 종류 B는 삼각형. 색은 층별 데모와 같게 원점 기준 각도로 정한다(종류 A 색상 140° → 225°, 종류 B 0° → 48°). 오른쪽 패널은 섞은 라벨의 모양과 색으로 그린다.
  - 테스트 점(보기를 켰을 때): 두 패널 모두 실제 라벨의 모양과 색으로 속 빈 마커를 그린다. 신경망의 예측이 실제 라벨과 다르면 진한 회색 테두리를 두른다.
  - 패널 아래 숫자: 학습 정확도와 테스트 정확도. 테스트 점 보기를 끄면 테스트 정확도 자리에 –를 둔다.
- 아래: 걸음 수와 두 패널의 학습 손실 곡선. 실제 라벨은 검은 실선, 섞은 라벨은 빨간 점선이고, 제목에 그래프 위 끝의 손실 값을 적는다. 기록이 3,000개를 넘으면 절반으로 솎는다.
- 두 패널이 처음으로 함께 학습 정확도 100%가 되면 학습을 멈추고 "Paused: both networks classify every training point correctly."를 적는다. 13,000걸음(`PRESET.maxSteps`)에서도 멈춘다. 멈춘 뒤 학습을 다시 누르면 이어서 학습한다.
- 창 폭이 1,180px보다 좁으면 두 패널을 위아래로 놓는다.

## 데이터

- 학습 점: 층별 2차원 데모의 Two moons와 같은 200개(종류별 100개, 시드 `lb|v1|data|moons`). 층별 데모의 점 생성 코드를 그대로 복사했다.
- 테스트 점: 층별 데모의 테스트 점과 같은 100개(종류별 50개, 시드 `lb|v1|test|moons`). 학습에 쓰지 않는다.
- 두 데모의 점이 같은지는 `test/core.test.js`가 층별 데모의 `index.html`을 불러 좌표와 라벨을 대조한다. 테스트 점 대조는 층별 데모에 `makeTestData`가 있을 때만 돌고, 없으면 건너뛴다.
- 섞은 라벨: 학습 점 200개의 라벨을 시드 `ms|v1|shuffle|1`의 Fisher-Yates로 한 번 섞는다. 종류별 개수는 100개씩 그대로이고, 라벨이 바뀐 점은 114개(종류 A에서 B로 57개, B에서 A로 57개)다. 점의 좌표는 바꾸지 않는다.

## 모델과 학습

- 신경망: 입력 2 → H → H → 1. 은닉층 둘은 tanh이고, 출력 z에 sigmoid를 씌운 값이 종류 B일 확률이다. H는 4, 16, 64, 256.
- 처음 노브 값: 시드 `ms|init|<1 + 초기화 횟수>`의 정규분포에서 W1(표준편차 √(1/2)), W2(√(1/H)), w3(√(1/H)) 순서로 뽑고 편향은 0으로 둔다. 두 패널을 같은 시드로 만들어 처음 값이 같다. 폭을 바꾸면 초기화 횟수를 0으로 되돌린다.
- 손실: 학습 점 200개의 이진 교차 엔트로피 평균. 기울기는 역전파로 구하고 테스트에서 중앙 차분과 대조한다.
- 갱신: 한 걸음에 200점 전체를 쓰는 Adam(β₁ 0.9, β₂ 0.999, ε 1e−8, 편향 보정), 학습률 0.01.

## 테스트 정확도를 실제 라벨로 재는 이유

오른쪽 신경망은 섞은 라벨을 외웠다. 이 신경망이 두 초승달의 모양을 배웠는지는 섞은 라벨로 잰 정확도로는 알 수 없다. 섞은 라벨은 점의 위치와 상관이 없으므로, 테스트 점에도 라벨을 섞어 붙이면 어떤 신경망이든 정확도가 50% 근처로 나온다.
그래서 두 패널 모두 테스트 점의 실제 라벨로 정확도를 잰다. 왼쪽은 학습 정확도와 테스트 정확도가 함께 100%이고, 오른쪽은 학습 정확도 100%와 테스트 정확도 44%가 함께 나온다.
오른쪽 테스트 정확도가 50%보다 조금 낮은 것은 섞은 뒤 라벨이 바뀐 점이 200개 중 114개(57%)이기 때문이다. 테스트 점의 예측은 대개 가까운 학습 점의 섞은 라벨을 따르므로 실제 라벨과 맞는 비율이 43% 근처가 된다.

## 학습률과 걸음 수 실측

`node test/calibrate.js <폭> <학습률,...>`로 폭마다 시드 1…30을 최대 6,000걸음까지 돌렸다. 시드마다 같은 처음 노브 값에서 실제 라벨과 섞은 라벨을 따로 학습한다.
도달은 학습 점 200개를 모두 맞힌 시드 수이고, 걸음은 그때까지의 갱신 횟수다. 최종 학습 정확도와 테스트 정확도는 학습을 멈춘 때의 값이다(100%에 닿은 걸음의 갱신 직후, 닿지 못하면 6,000걸음 뒤).
걸음당 ms는 패널 하나의 한 걸음이다. 이 컴퓨터(16코어)에서 Node 24로 다른 계산 작업과 함께 돌린 값이라 조용한 컴퓨터보다 느릴 수 있다.

| 폭 | 학습률 | 실제 라벨: 도달, 걸음 중앙값, 테스트 정확도 중앙값 | 섞은 라벨: 도달, 걸음 중앙값, 최종 학습 정확도 중앙값, 테스트 정확도 중앙값 | 걸음당 ms |
| --- | --- | --- | --- | --- |
| 4 | 0.003 | 30/30, 812, 100% | 0/30, 없음, 69.5%, 40.5% | 0.06 |
| 4 | 0.01 | 30/30, 266.5, 100% | 0/30, 없음, 70.25%, 42% | 0.06 |
| 16 | 0.003 | 30/30, 341, 100% | 0/30, 없음, 93.5%, 43% | 0.3 |
| 16 | 0.01 | 30/30, 122.5, 100% | 0/30, 없음, 93.5%, 44% | 0.3 |
| 64 | 0.003 | 30/30, 142.5, 100% | 27/30, 2,482, 99.5%, 45% | 3.0 |
| 64 | 0.01 | 30/30, 59.5, 100% | 28/30, 1,760.5, 99.5%, 44.5% | 2.9 |
| 256 | 0.01 | 30/30, 51.5, 100% | 30/30, 1,709.5, 99.5%, 47% | 38 |

정한 값은 `MS.PRESET = { lr: 0.01, steps: 6500, maxSteps: 13000 }`이다.

- 학습률: 구현 계획은 폭 64에서 섞은 라벨이 시드 30개 모두 닿는 학습률 중 걸음 중앙값이 작은 것을 고르기로 했지만, 두 후보 모두 30개에 못 미쳤다(0.01에서 28개, 0.003에서 27개). 더 많이 닿고 걸음 중앙값도 작은 0.01로 정했다.
  0.01에서 닿지 못한 두 시드를 20,000걸음까지 이어서 재 보니 시드 3은 8,551걸음에 닿았고, 시드 28은 20,000걸음 뒤에도 98%였다.
- `steps`: 0.01에서 닿은 28개 중 가장 늦은 5,353걸음(시드 27)의 1.2배를 500 단위로 올린 6,500. 코어 테스트가 이 걸음 수 안에 폭 64가 시드 1에서 두 라벨을 모두 외우는지 본다.
- `maxSteps`: 화면이 스스로 학습을 멈추는 걸음으로 `steps`의 두 배인 13,000. 폭 256에서 가장 늦은 시드 7(5,829걸음)도 이 안에 닿는다.
- 폭 4: 학습률 0.01로 6,500걸음까지 다시 재도 섞은 라벨에 닿은 시드가 없었다(0/30, 최종 학습 정확도 중앙값 70.5%). 그래서 코어 테스트의 폭 4 조건(시드 1이 `steps` 안에 섞은 라벨을 못 외운다)을 계획대로 둔다.
- 기본 시드 1: 폭 64는 실제 라벨 47걸음, 섞은 라벨 1,417걸음. 폭 256은 46걸음, 1,406걸음. 폭 16은 실제 라벨 112걸음, 섞은 라벨은 6,000걸음 뒤 94.5%. 폭 4는 실제 라벨 189걸음, 섞은 라벨은 6,000걸음 뒤 71.5%.
- 100%에 처음 닿은 바로 다음 걸음에서 한두 점이 다시 틀리는 일이 흔하다. 닿은 경우에도 표의 최종 학습 정확도 중앙값이 99.5%인 이유다.
- 실측과 코어 테스트는 Node 24에서 돌린다. 헤드리스 크로미움 151에서 같은 학습을 돌리면 10걸음 뒤에 이미 유효숫자 16~17번째 자리에서 값이 달라지고, 그 차이가 쌓여 시드 1, 폭 64의 섞은 라벨이 1,417걸음 대신 1,412걸음에 100%가 됐다(실제 라벨은 폭 64에서 두 곳 모두 47걸음, 폭 4에서 두 곳 모두 189걸음). 화면의 걸음 수는 이 표와 몇 걸음씩 다를 수 있다.
- 화면은 두 패널이 함께 100%인 프레임이 끝날 때 멈춘다. 크로미움 151에서 시드 1, 폭 64는 프레임마다 1걸음이면 1,412걸음(38초쯤), 5걸음이면 1,415걸음(15초쯤), 20걸음이면 1,420걸음(10초쯤)에서 멈췄다. 5걸음과 20걸음에서 멈췄을 때 테스트 정확도는 왼쪽 100%, 오른쪽 44%였다.
- 실측에 걸린 시간: 폭 4는 30초, 폭 16은 2분, 폭 64는 두 학습률에 9분쯤, 폭 256은 한 학습률에 36분(시드를 다섯 프로세스로 나눠 돌려 9분쯤).

## 구조

한 파일 안에 스크립트가 두 개다.

- `<script id="ms-core">` (전역 `MS`): 난수, 초승달 점, 라벨 섞기, 신경망, 역전파, Adam, 프리셋, 문자열 표. DOM을 건드리지 않는다.
  - `rngOf(str)`, `gaussOf(rng)`: 층별 데모와 같은 시드 난수.
  - `makeMoons('train' | 'test')`는 `{ n, X, y }`를 돌려준다.
  - `shuffleLabels(y, seed)`는 섞은 새 `Uint8Array`를 돌려준다. `SHUFFLE_SEED = 1`.
  - `WIDTHS = [4, 16, 64, 256]`, `DEFAULT_WIDTH = 64`.
  - `initNet(H, seed)`는 `{ H, W1, b1, W2, b2, w3, c }`, `params(net)`은 `[W1, b1, W2, b2, w3, c]`.
  - `logit(net, x, y)`, `evaluate(net, data)`는 `{ loss, acc }`, `lossGrad(net, data)`는 `{ loss, acc, g }`(g는 `params` 순서).
  - `makeAdam(net)`, `adamStep(net, st, data, lr)`은 갱신 전의 `{ loss, acc }`.
  - `PRESET = { lr, steps, maxSteps }`, `STRINGS = { en, ko }`, `t(lang, key, params)`.
- `<script id="ms-ui">` (전역 `MSUI`): 화면, 학습 루프, 결정 영역, URL 옵션.
  - `MSUI.hooks`(스모크 테스트와 캡처 스크립트용): `setWidth(w)`, `train(n)`, `startTraining()`, `stopTraining()`, `reset()`, `setShowTest(on)`, `shadeNow()`(두 패널의 결정 영역 격자를 한 번에 계산하고 그린다), `draw()`, `state()`.
  - `train(n)`, `setWidth(w)`, `reset()`은 끝난 뒤의 `state()`를 돌려준다. `state()`는 `{ width, steps, training, showTest, lang, real: { loss, trainAcc, testAcc }, shuf: { loss, trainAcc, testAcc } }`이고, `testAcc`는 테스트 점 보기와 상관없이 계산한다.
  - 요소 id: `#segWidth`(칩은 `button[data-v]`), `#bTrain`, `#bReset`, `#speed`, `#bTest`, `#panels`, `#panelReal`와 `#panelShuf`(각각 안에 `h3`, `canvas.pc`, `b.tr`, `b.te`), `#legend`, `#lossWrap`, `#sSteps`, `#lossCv`, `#note`, `#fine`.

코어만 Node에서 쓰려면:

```js
const core = require('./test/load.js')();
const train = core.makeMoons('train');
const net = core.initNet(64, 1), st = core.makeAdam(net);
core.adamStep(net, st, train, core.PRESET.lr);   // { loss, acc } before the update
```

## 테스트

`test/`는 게시할 때 복사되지 않는다.

```bash
node --test test/*.test.js                          # 코어 (8개, 5초쯤)
node test/calibrate.js 64 0.003,0.01                # 폭 하나, 시드 1…30 실측 (폭 64에서 9분쯤)
node test/calibrate.js --summary a.jsonl b.jsonl    # 여러 프로세스로 나눠 잰 출력을 합친 요약
uv run --with playwright python test/smoke.py       # 브라우저 스모크, 캡처는 test/shots/ (1분쯤)
```

- 코어 테스트: 두 데모의 학습 점 대조, 테스트 점 대조(층별 데모에 `makeTestData`가 있을 때), 섞은 라벨의 시드 고정과 종류별 개수, 역전파와 중앙 차분, 두 패널의 처음 노브 값이 같고 Adam이 손실을 줄이는지, 문자열 표 en과 ko의 키와 자리표시, 폭 64가 `PRESET.steps` 안에 두 라벨을 모두 외우고 폭 4는 섞은 라벨을 못 외우는지.
- 스모크: 콘솔 에러, 기본 화면(폭 64, 걸음 0, 두 캔버스에 그림), 폭 칩, `train(50)`, 테스트 점 보기, 초기화, `Space`로 학습과 멈춤, 두 패널이 100%가 되면 저절로 멈추는지, `maxSteps`에서 멈추는지, URL 옵션(`width`, `test`, `train`, `lang=ko`), 폭 256, 좁은 창에서 패널을 위아래로 놓는지.
  캡처: `open.png`, `fit-64.png`, `fit-64-test.png`, `fit-64-panels-1280.png`, `fit-64-loss-1280.png`, `width-4.png`, `ko-300.png`, `narrow.png`.

## 조작

- `Space`: 학습과 멈춤 (선택 상자에 초점이 있을 때는 제외)
- 폭 칩: 그 폭의 신경망을 처음 노브 값부터 다시 만든다(초기화 횟수 0). 지금 폭의 칩을 누르면 아무 일도 하지 않는다.
- 초기화: 두 패널에 같은 새 처음 노브 값을 뽑고 걸음 수와 손실 곡선을 비운다.

## 하지 않는 것

- 층별 재생: 은닉층 폭이 2가 아니라서 층마다 평면 하나에 그릴 수 없다. 층이 공간을 바꾸는 과정은 층별 2차원 데모에서 본다.
- 라벨을 섞는 비율 슬라이더: 전부 한 번 섞은 경우 하나만 둔다.
- 다른 데이터: 층별 데모의 초승달만 쓴다.
